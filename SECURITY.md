# Security Policy

## Official Distribution Channels
To protect yourself from malware and impersonation attempts, please ensure you only download and install `alerts-in-ua-php` from our official sources:
- **Composer (Packagist):** `composer require fyennyi/alerts-in-ua-php`
- **GitHub Releases:** Official repository `https://github.com/Fyennyi/alerts-in-ua-php`

> [!WARNING]
> We **never** distribute this library as standalone `.exe` or `.zip` installers intended for manual execution. If you find a repository offering a "quick install" archive, it is likely malware. Please report it immediately.

## Supported Versions
Currently, the library is in the `0.x.x` development phase. Security updates and patches are only provided for the **latest** available release.

| Version | Supported |
|---|---|
| 0.x.x (Latest release) | :white_check_mark: |
| Older versions | :x: |

## Reporting a Vulnerability
We take the security of this project very seriously. If you discover a security vulnerability, please **DO NOT** open a public issue. 

Instead, please report it privately:
1. Send an email directly to **chernegasergiy3@gmail.com**.
2. Or use the [GitHub Security Advisories](https://github.com/Fyennyi/alerts-in-ua-php/security/advisories) feature to report it privately.

Please provide a clear description of the issue and steps to reproduce it. You should receive a response within 48 hours. We will work with you to verify the vulnerability and release a patch as quickly as possible.
